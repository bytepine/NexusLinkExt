# NexusLinkExt

可选插件的 [NexusLink](https://github.com/bytepine/NexusLink) Capability。当前包含 UnLua。

| 模块 | 类型 | 内容 |
|------|------|------|
| `NexusLinkExt_UnLua` | Runtime | 运行时 Lua Capability、`FNexusLuaUtils` |
| `NexusLinkExtEditor_UnLua` | Editor | 蓝图 UnLua 绑定 |

依赖 NexusLink，并在检测到 UnLua 时链接它。示例工程 [NexusUnreal](https://github.com/bytepine/NexusUnreal) 以 git 子模块挂载本插件（`Plugins/NexusLinkExt`）。
